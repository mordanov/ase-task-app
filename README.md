# Keycloak Auth App

Full-stack authentication platform with Keycloak, FastAPI, and React.

## Quick start

```bash
docker compose up -d
```

Wait ~90 seconds for Keycloak to initialise, then open:

- **App:** http://localhost:3000
- **Keycloak console:** http://localhost:8080 (admin / admin)
- **API docs:** http://localhost:8000/docs

Default admin login: `admin@example.com` / `admin`

See `docs/README.md` for the full documentation.
